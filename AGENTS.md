# AGENTS.md: shared info

This repo is a team knowledge base. You read it while working in another project. It is not that project: never copy files between the two.

- At the start of each chat, read [knowledge/README.md](./knowledge/README.md). When a message matches an entry's trigger, follow that entry exactly, including its reply format.
- Before other tasks, read the entries on the topic and apply them.
- When the user asks about something covered here, answer from the entry and name its file, unless the entry sets its own reply format.
- If an entry contradicts the project or seems out of date, tell the user.
- This repo is read-only for you. Don't edit, commit or push here. To suggest an entry, write it out in your reply and let the user add it.
