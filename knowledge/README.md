## Adding an entry

- Each file covers one topic and stands on its own: an agent new to the project can use it as is.
- An entry that sets how to answer a kind of message needs a trigger: what the message starts with or asks for.
- Give the file a short lowercase name with hyphens, like `triage.md`, and list it in the table above.
- Keep it safe to publish: no customer names or details, no passwords or keys.
